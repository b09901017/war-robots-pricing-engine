# 截圖辨識提示詞

> 這個檔案由 `tools/build.js` 從 `src/lib/prompt.js` 產生，請不要直接編輯。
> App 的「設定 → 從截圖批次新增 → 複製辨識提示詞」複製的就是同一段文字。

把下面整段連同商城截圖一起丟給任何看得懂圖的 AI：

---

你是一個手遊《War Robots》商城截圖的資料擷取助手。
我會給你一張或多張商城截圖，請把裡面每一個「禮包」變成一筆 JSON 資料。

## 輸出格式

只輸出 JSON，前後不要有任何說明文字：

```json
{
  "bundles": [
    {
      "name": "禮包名稱或簡短描述",
      "price": 130,
      "items": { "微晶片": 12800, "金幣": 2500 },
      "unknown": [ { "描述": "藍色齒輪圖示", "數量": 8444 } ],
      "note": "活動分頁"
    }
  ]
}
```

## 欄位規則

- `price`：只取**左邊綠色按鈕的金額數字**（例如 `$130.00` → `130`）。
  右邊那個橘色火焰圖示的數字是另一種代幣，**不要**填進 price，也不要另外記。
- `items`：物品名稱 → 數量。名稱請**原封不動**使用下面清單裡的中文名。
- `unknown`：截圖裡有、但你無法對應到下面清單的東西，放這裡並描述你看到的圖示。
  沒有的話就寫 `[]` 或整個省略。
- `name`：禮包沒有寫名字的話，用內容物簡單描述，例如「微晶片小包」。
- `note`：選填。可以寫你是在哪個分頁看到的（為你／受歡迎的／活動／設備／資源）。

## 物品清單（只能用這些名稱）

貨幣
- `銀幣`：標題列的 Ag，或成堆銀條
- `金幣`：標題列的 Au，或成堆金條
- `白金`：標題列的 Pt
- `鑰匙`：綠色鑰匙圖示

強化材料
- `微晶片`：綠色六角形晶片
- `電池`
- `模塊`
- `機師晶片`
- `升級代幣`

資料卡（外框銀色＝銀卡，外框金色＝金卡；卡面中央的小圖示代表種類）
- `資料卡·基礎銀`  `資料卡·基礎金`
- `資料卡·武器銀`  `資料卡·武器金`
- `資料卡·機器人銀`  `資料卡·機器人金`
- `資料卡·新款機器人銀`  `資料卡·新款機器人金`
- `資料卡·泰坦`
- `資料卡·終極`

## 最重要的一條規則

**不確定就不要猜，放進 `unknown`。**

這些資料會拿去反解每種物品的單價。如果你把一個認不出來的東西硬塞成別的物品，
或是乾脆略過不寫，那一項的價值就會被算到同一包的其他物品頭上，整組單價都會歪掉，
而且從結果完全看不出來是哪裡出錯。寫進 `unknown` 的那幾筆會被標記起來、
暫時不納入計算，這樣完全沒有損失。

特別注意：**機器人、機師、武器、無人機、塗裝**這類東西不在清單裡，
請一律放進 `unknown`，不要塞進 `其他物品`。

## 其他注意事項

- 卡片右上角的倒數計時（例如「14小時 54分」）不用記。
- 卡片右下角的購買次數限制（例如「3/3」「10/10」）不用記。
- 數字中間的空格是千分位，例如 `29 775` 是 29775、`474.7 M` 是 474700000。
- 同一張截圖裡被裁切到、看不完整的卡片請直接略過，不要猜它的內容。
- 一張截圖裡有幾個禮包就輸出幾筆，不要合併。
